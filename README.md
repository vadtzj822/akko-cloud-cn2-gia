## 线路优化在哪里：去程各走各的，回程分两种

先去程。电信走 CN2 直连法兰克福，联通走 AS4837 转 AS10099 直连，移动走 CMI 直连，三家各自骨干网出去，不绕道美国。这个结构在国内访问欧洲的机器里算干净。

回程是关键。2025 年 3 月那次升级之后，**电信回程走 CN2 GIA，联通回程强制走电信的 CN2 GIA，移动回程走 CMIN2**。CMIN2 是中国移动自己的精品国际线路，和 CN2 GIA 同属高端优化范畴，但走的不是电信 59.43 那段骨干。所以移动用户 traceroute 出来看不到 CN2 的 59.43 节点，这是正常的，不是线路降级。

前排不少文章写“三网回程统一 CN2 GIA”，那是 2025 年 3 月之前的口径。如果你拿移动卡去测，发现回程没有 59.43，别急着以为买到假货，先对一下时间。想自己验证，官方给的测试 IP 是 **185.217.109.94**，配一个 BestTrace 看回程经过哪些 AS，比看文章描述靠谱。

延迟方面，国内多地 ping 平均在 **180ms 左右**（早期 Intel 平台测过 177ms，AMD EPYC 平台约 182ms）。走普通国际路由的欧洲机器，这个数字常见 250ms 起。晚高峰的表现，有测评提到国内部分地区上下行能跑到标称带宽的大部分，国际节点 Speedtest 稳定。

硬件是 2025 年 3 月换的 AMD EPYC，同一批测评里硬盘 I/O 测到约 **734MB/s**，早期 Intel 平台是 230MB/s；UnixBench 2 核 1 线程约 1381 分，1 核 1 线程约 806 分。这个跑分对应的是建站、轻量应用、流媒体解锁这类负载，不是重计算。

流媒体方面，德国原生 IP，有测评称实测可解锁 Netflix、TikTok 等主流跨区服务，部分套餐支持 DNS 解锁。解锁能力会随平台策略变，下单前自己用测试 IP 验一遍更稳。

## 下单前先测一轮，别省这十分钟

VPS 这个东西，同一个机房不同省份不同运营商的体验能差出一截。官方给了测试 IP 185.217.109.94，还有一个以 fralg 开头的官方测速页，可以先用起来。

具体做什么：

1. 从你常用的网络环境 ping 这个 IP，看平均延迟和丢包。180ms 上下属于正常，如果你那边稳定 250ms 以上，说明你的出口线路绕了。
2. 跑 traceroute 或 BestTrace 看回程。电信、联通应该能看到 59.43 网段的 CN2 节点；移动看到的是 CMIN2 的路径，不是 59.43，这不代表有问题。
3. 在晚高峰（晚上八九点）再测一次。白天的数据好看不代表晚高峰好看，CN2 GIA 相对普通 163 骨干的价值主要体现在这个时段。
4. 有条件的话从测速页拉个文件，看实际下载速度和你本地带宽的匹配度。

测完觉得可以，再下单。
